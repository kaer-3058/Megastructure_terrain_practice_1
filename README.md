## 迷宫的通路/被困概率

机制：每个单位格子里，每面墙有 $\frac{1}{5}$ 概率放置，且事件互斥，也就是一个格子最多只会放置一面墙。

被围死的概率： $P(\text{被1格围死}) = \left(\frac{1}{5}\right)^4 = \frac{1}{625} = 0.16\%$ ，因此 $P(\text{被困}) > \frac{1}{625} > 0$ 

网格中的每一条内部公共边，同时属于两个相邻的格子（例如格子A的右边和格子B的左边）。只有当这两个格子都没有把墙放在这条公共边上时，这条边才是打通的。

格子A不把墙放这里的概率： $1 - \frac{1}{5} = \frac{4}{5}$ 。格子B不把墙放这里的概率： $1 - \frac{1}{5} = \frac{4}{5}$ 。

由于不同格子的放墙选择是相互独立的，一条边保持畅通的概率为： $p_{\text{open}} = \frac{4}{5} \times \frac{4}{5} = \frac{16}{25} = 0.64$ 

在二维正方晶格的独立键渗流中，Kesten 定理证明了临界概率为 $p_c = \frac{1}{2}$ 。其含义是：当畅通概率大于 $\frac{1}{2}$ 时，图上几乎必然存在一个连通到无穷远的“无限大连通分量”。

因此，绝大多数情况能无限探索。整个无限平面上存在一个贯穿无穷远的巨型连通网络。有超过98%的概率刚好落在这个巨型网络上，只要不走回头路，就可以一直走下去，永远能找到通往更远处的 “出口”。

放置墙面的随机源使用了破碎噪声 `scattered_random` (噪声信息见下文) ，因此可以视为是具有较好的随机性的，所以本理论成立。

## 制作原理

#### 1.余弦波 - 2D

原生密度函数没有余弦，使用帕德逼近+取整取余进行周期化，得到了近似的余弦。作用于地形深度，因此是对地形高度进行调整以体现出余弦波。

公式：

$$
\begin{array}{l}
	\mathrm{Pade}_{\cos}\left( x \right) =\frac{30}{4x^2+5}-5\\
	T\left( x \right) =x-2\lfloor \frac{2x+1}{4} \rfloor\\
	\cos \left( \pi x \right) \approx \begin{cases}
	\mathrm{Pade}_{\cos}\left( T\left( x \right) \right)&		,\ \mathrm{if}\ -\frac{1}{2}\leqslant T\left( x \right) <\frac{1}{2}\\
	-\mathrm{Pade}_{\cos}\left( T\left( x \right) -1 \right)&		,\ \mathrm{other}\\
\end{cases}\\
\end{array}
$$

#### 2.余弦波 - 3D

直接把最终密度乘上以三维距离为自变量的余弦函数。余弦为正值的部分还是原样，为负值的部分会让空气地形翻转，因此这实际上是一个个球心为原点的互相嵌套的球。

#### 3.随机迷宫地形 

1. 利用取整函数进行网格化采样噪声，这样得到了离散随机源。

2. 对噪声进行采样和理论分析，得到噪声的均值、标准差，代入正态分布密度函数，根据需要的概率反推噪声值域，得到指定概率的随机源。

3. 利用取整可以进行浮点数的整除，继而可计算浮点数和浮点数的取余，得到周期和网格一致的二维周期函数。

4. 利用 `range_choice` 范围测试函数，对符合条件的概率和周期函数区间设置为1，否则为0，得到了是否放置迷宫墙的布尔函数。

5. 直接把值加到最终密度上，因此迷宫墙从世界建筑上限贯穿至下限。

由于是在地物/结构生成前就生成好的，因此并不是绝对的路障，会被结构/地物等穿过。

#### 4.随机高度的柱子地形

用噪声做均匀分布：

对均值为 $\mu$ ，标准差为 $\sigma$ 的的噪声进行采样，采样区间为 $[L,U]$ 。若要将噪声值进行映射，以均等的概率映射到 $[a,b]$ ，则映射公式为：
$$
f\left( x \right) =a+\left( b-a \right) \frac{\mathrm{erf}\left( \frac{x-\mu}{\sqrt{2}\sigma} \right) -\mathrm{erf}\left( \frac{L-\mu}{\sqrt{2}\sigma} \right)}{\mathrm{erf}\left( \frac{U-\mu}{\sqrt{2}\sigma} \right) -\mathrm{erf}\left( \frac{L-\mu}{\sqrt{2}\sigma} \right)}
$$

其中 $\mathrm{erf}(x)$ 是误差函数。定义为：

$$
\mathrm{erf}\left( x \right) =\frac{2}{\sqrt{\pi}}\int_0^x{e^{-t^2}\,\mathrm{d}t}
$$

有近似公式：

$$
\mathrm{erf}\left( x \right) \approx 1-\frac{1}{\left( 1+a_1x+a_2x^2+a_3x^3+a_4x^4 \right) ^4},\ x\geqslant 0
$$

其中 $a_1 = 0.278393,\ a_2 = 0.230389,\ a_3 = 0.000972,\ a_4 = 0.078108$ 

利用其性质 $\mathrm{erf}(x)=-\mathrm{erf}(-x)$ 可以计算整个函数。

由此得，把破碎噪声 `scattered_random` 的 $[-0.92,\,0.92]$ 区间等概率映射到 $[-64,\,320]$ 的函数为：

$$
M\left( x \right) =128+\frac{192\,\mathrm{erf}\left( \frac{5\sqrt{2}}{3}x \right)}{\mathrm{erf}\left( \frac{23\sqrt{2}}{15} \right)}
$$

## 制作经验总结

1. 若函数是直接应用于深度，海平面上下分开算，注意海平面64至-64的深度跨度为1，海平面上的深度跨度为2。

2. 由于密度函数里都是float运算，而且还有个字面量的输入值限制：`-1000000.0` ≤值≤ `1000000.0`。

   而xz坐标的绝对值上限约为30000000，大于字面量上限。

   因此如果想在密度函数里获取xz坐标，只能是通过浮点运算映射到一个较小区间后放大。

3. 综上所述，密度函数里获取到的坐标和真实坐标一定存在误差，因此，像计算 `noise` 函数的坐标偏移等操作，尽量是不要使用和真实坐标作差进行偏移，而是直接把 `noise` 函数的坐标缩设为0，然后直接输入函数值作为偏移量。

4. 由于float精度问题，使用取整函数后，取整的边界会存在比double明显得多的跳变问题。因此：尽量不要用"有效数字的十进制位数的长度超过七位"的数值作为边界判断条件；边界判断条件要设置冗余量，比如大于60设置为大于60.5。

   比如cos函数，利用帕德逼近+取整取余函数周期折返，其中存在很多含π的常数，会导致浮点误差进一步放大，理论上就会存在误差。因此我换成了帕德逼近cos(πx)函数，这样周期变成了2，很多常数也都变成了有限小数或整数，仅在自变量的系数上含π。

5. `gradient` 函数进行坐标映射时，会直接把坐标和 `from_coordinate` 参数相加减，这个操作会让映射值直接变成了误差来源。虽然接收值是int，但是仍然会按float算 (这种做法很不当)。

   因此，如果需要较大范围的映射，比如±30000000的全坐标映射时，需要从端点0拆分为两段映射，然后相加。

6. 目前想在密度函数/表面规则阶段获取随机数，仍需靠噪声。因此一个质量好的噪声源很重要。噪声可以用正态分布拟合，因此想通过噪声获取指定概率的随机源，需要高等数学方法 (积分求值，根据值求解积分限方程)。

7. 噪声的频率分布也很重要。虽然计算概率理论上只需要均值和标准差/方差，但是玩家进游戏能直接看到的是局部分布，而局部分布和噪声频率分布有关，正所谓1/3概率和1/3概率还不一样。有的是一大块，有的是细碎面条。

## 噪声设置之外的机制 - 水体选择器

MC的含水层，噪声设置和密度函数里能配置的只是一部分，它还有一个硬编码的部分叫 “水体选择器”：

水体选择器-水：当y轴高度不高于海平面且 `final_density` (最终密度) 函数值为负时，强制放置默认流体，含水层噪声只能让其一部分为空气。

水体选择器-岩浆：密度函数 `lava` 函数仅在y≤-10时才会应用，且在y≤-54时强制把默认流体替换为岩浆。且 `lava` 函数是按64x40x64的格子采样一次。

即使在噪声设置里把整个含水层删了，也无法关闭流体选择器。
